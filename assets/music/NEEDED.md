# Install the manual music downloads

Download the MP3 from each linked page using **Free download** and save it at the path shown.
Create the `.incoming` folder if it does not exist. Run `python scripts/fetch_assets.py` from the repo root.

| Download | Save the MP3 here | Installed WAV |
|---|---|---|
| [Tunetank — tunetank_retro](https://pixabay.com/music/synthwave-synthwave-80s-retro-background-music-349034/) | `assets/music/.incoming/tunetank_retro.mp3` | `assets/music/tunetank_retro.wav` |
| [Begench_Begenjov — begench_night](https://pixabay.com/music/synthwave-night-221519/) | `assets/music/.incoming/begench_night.mp3` | `assets/music/begench_night.wav` |
| [OiBeats — oibeats_dark_light](https://pixabay.com/music/trap-trap-beat-instrumental-dark-light-584768/) | `assets/music/.incoming/oibeats_dark_light.mp3` | `assets/music/oibeats_dark_light.wav` |
| [OctoSound — octosound_trap_beats](https://pixabay.com/music/beats-the-trap-beats-265154/) | `assets/music/.incoming/octosound_trap_beats.mp3` | `assets/music/octosound_trap_beats.wav` |

The five OpenGameArt beds are downloaded automatically.
