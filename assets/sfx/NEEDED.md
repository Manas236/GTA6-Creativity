# Install the manual sfx downloads

Download the MP3 from each linked page using **Free download** and save it at the path shown.
Create the `.incoming` folder if it does not exist. Run `python scripts/fetch_assets.py` from the repo root.

| Download | Save the MP3 here | Installed WAV |
|---|---|---|
| [spinopel — siren_02](https://pixabay.com/sound-effects/city-police-siren-short-409404/) | `assets/sfx/.incoming/siren_02.mp3` | `assets/sfx/siren/siren_02.wav` |
| [freesound_community — record_scratch_01](https://pixabay.com/sound-effects/film-special-effects-record-scratch-108233/) | `assets/sfx/.incoming/record_scratch_01.mp3` | `assets/sfx/record_scratch/record_scratch_01.wav` |
| [freesound_community — record_scratch_02](https://pixabay.com/sound-effects/film-special-effects-dj-scratch-87179/) | `assets/sfx/.incoming/record_scratch_02.mp3` | `assets/sfx/record_scratch/record_scratch_02.wav` |

The remaining cues are downloaded automatically from pinned CC0 mirrors in the manifest.
